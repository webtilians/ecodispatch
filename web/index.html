INVESTIGACIÓN ABIERTA · v1.1.1

¿Cuánta capacidad desperdiciamos por asignar mal los recursos?

EcoDispatch separa el problema en tres capas: dónde colocar recursos antes de una emergencia, cómo asignarlos cuando llegan varios incidentes a la vez y cómo mantener buena cobertura durante una jornada completa.

Cómo leer estos resultados

Cada escenario se genera de forma independiente a partir de una semilla reproducible. El intervalo mostrado es un IC del 95 % para la media (aproximación normal). P5/P50/P95 describen la distribución empírica. Los stress tests de arriba no entran en esta validación.

LÍMITES

Banco de pruebas, no sistema operativo real.

Los incidentes, bases y perfiles de riesgo son sintéticos sobre coordenadas reales de Málaga. Los stress tests buscan deliberadamente casos difíciles; la web los etiqueta para no presentarlos como rendimiento medio. Las rutas reales, tiempos de servicio e incidentes simultáneos con datos reales llegarán en versiones posteriores.
