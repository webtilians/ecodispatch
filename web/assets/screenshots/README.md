# EcoDispatch screenshots

Put milestone screenshots in this folder.

Recommended naming:

```
v0.1-dashboard.png
v0.2-wildfire-simulation.png
v0.3-real-road-network.png
```

Then add the relative image path to `web/data/timeline.json`:

```json
"screenshot": "./assets/screenshots/v0.2-wildfire-simulation.png"
```

The public dashboard will display it automatically in the evolution log.
